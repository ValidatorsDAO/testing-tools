# node_bench examples

This directory holds example run artifacts and metadata for common environments. Each subdirectory describes the machine specs and how to collect node_bench output from `$HOME/results` (or `RESULTS_DIR` if set) into that example folder.

Available examples:

- `validators_vps_amsterdam/` — Validators DAO VPS (Amsterdam), 4 vCPU / 16GB RAM / 100GB disk.
- `gcp_c4d_standard_4/` — Google Cloud c4d-standard-4 (AMD Turin), 4 vCPU / 15GB RAM / 10GB SSD.
